# 🥬 ຮ້ານຂາຍຜັກສົດ (Fresh Market POS & Inventory System)

ເວັບແອັບລະບົບຂາຍໜ້າຮ້ານ (POS), ຄຸ້ມຄອງສະຕັອກສິນຄ້າ, ບັນຊີລາຍຮັບ-ລາຍຈ່າຍ, ອຸປະກອນ ແລະ ໜີ້ສິນ ສຳລັບຮ້ານຂາຍຜັກສົດ ແລະ ຕະຫຼາດສົດ.

## ✨ ຄຸນສົມບັດຫຼັກ (Features)
- 🛒 **ລະບົບຂາຍໜ້າຮ້ານ (POS)**: ຄິດໄລ່ເງິນ, ຮອງຮັບເງິນສົດ & ໂອນ BCEL One QR, ພິມໃບບິນ Thermal 80mm / 58mm.
- 📦 **ຄຸ້ມຄອງສິນຄ້າ & ບາໂຄ້ດ**: ລະບົບສ້າງບາໂຄ້ດອັດຕະໂນມັດ, ຮອງຮັບຫົວໜ່ວຍຍ່ອຍ, ລາຄາຂາຍສົ່ງຕາມຈຳນວນ.
- 💰 **ລາຍຮັບ-ລາຍຈ່າຍ & ໜີ້ສິນ**: ບັນທຶກລາຍຈ່າຍ, ຕິດຕາມໜີ້ຕ້ອງຮັບ (ລູກຄ້າຕິດໜີ້) ແລະ ໜີ້ຕ້ອງສົ່ງ (ຕິດໜີ້ຜູ້ສະໜອງ).
- ☁️ **Cloud Sync**: ຮອງຮັບການຊິງຄ໌ຂໍ້ມູນອັດຕະໂນມັດໄປຍັງ Google Sheets.
- 📱 **ຮອງຮັບທຸກອຸປະກອນ**: ໃຊ້ງານໄດ້ທັງໃນຄອມພິວເຕີ, ແທັບເລັດ, ໂທລະສັບມືຖື ແລະ ເຄື່ອງ POS Sunmi V2 SE.

## 🚀 ວິທີໃຊ້ງານຜ່ານ GitHub Pages
1. Fork ຫຼື Upload ໄຟລ໌ທັງໝົດຂຶ້ນ GitHub Repository (ຕັ້ງຄ່າເປັນ **Public**).
2. ເຂົ້າໄປທີ່ **Settings** ➡️ **Pages**.
3. ໃນຫົວຂໍ້ **Branch** ເລືອກ `main` (ຫຼື `master`) ໂຟນເດີ `/(root)` ແລ້ວກົດ **Save**.
4. ເຂົ້າໃຊ້ງານຜ່ານລິ້ງ: `https://<your-username>.github.io/<repository-name>/`.
